## 使用方法

### 1. 手动编辑
直接编辑 CSV 文件，添加/修改持仓信息。只需填写前 5 个字段（代码、名称、持仓数量、成本单价、总成本），其他字段会自动计算。

### 2. 使用命令
```bash
# 添加到持仓
添加到持仓 160644 港美互联网 LOF 973 股 成本 2.05 元

# 查看持仓
查看持仓

# 生成今日建议
今日建议
```

### 3. 自动生成日报
调用 skill 会自动：
1. 读取此 CSV 文件
2. 获取实时净值
3. 计算最新盈亏
4. 生成操作建议
5. 更新 CSV 中的当前价字段

## 数据来源

### 实时净值获取
- **优先级 1**: 天天基金网 (fund.eastmoney.com)
- **优先级 2**: 新浪财经 (finance.sina.com.cn)
- **优先级 3**: 上海证券交易所/深圳证券交易所
- **优先级 4**: 东方财富网 (quote.eastmoney.com)

### 更新频率
- **ETF/LOF**: 交易日实时更新
- **QDII 基金**: T+1 日更新（隔夜净值）
- **普通基金**: 每个交易日收盘后更新

## 注意事项

1. **成本单价**: 请精确到小数点后 3 位
2. **持仓数量**: 整数或小数均可（基金可买小数份额）
3. **当前价**: 由系统自动获取，不要手动填写
4. **最后更新**: 系统自动记录，不要手动修改
5. **行业分类**: 建议填写，用于行业分散度分析
